# 던전헬퍼 통계 연결

기존 봇 DB와 작업을 유지하며 별도 인증 서버의 집계만 조회합니다.
`DROP_STATS_ORIGIN`(HTTPS 인증 서비스 주소), `DROP_STATS_READ_KEY`(서비스 읽기 키),
`DROP_STATS_GUILD_ID`(지정 Discord 서버)를 설정한 뒤 시작하면 명령을 추가합니다.
설정하지 않으면 기존 명령 목록을 유지합니다.

- `/드랍통계`: 한국 시간 오늘 던전별 영혼석/마력석 획득률·수량, 햄순이로 완료한 횟수
- `/오늘랭킹`: 영혼석 TOP 5, 마력석 TOP 5 별도 수량 순위
- `/내기록`: Discord interaction의 요청자 ID로 조회하여 본인에게만 표시

획득률은 획득 개수 / 햄순이로 완료한 판수 × 100입니다.
돌별 수량·완료 판수·퍼센티지를 두 개의 짧은 표에 표시합니다.
이는 수량 대비 지표이므로 한 판에 여러 개를 얻으면 100%를 넘을 수 있습니다.
던전별 판수가 모두 기록된 경우 해당 던전 판수를 사용합니다.
던전명이 없는 구버전 판수가 섞이면 원래 수량과 판수를 보존하고,
`던전 전체 기준` 또는 `어비스 전체 기준`을 표시합니다. 예전 판수를 특정 던전으로 추측하지 않습니다.
예: 예전 어비스 713판과 허상 59개는 어비스 전체 기준 8.3%입니다.
완료 판수가 0이면 비율은 `—`로 표시합니다.

지정 서버 이외에서는 조회할 수 없습니다. 닉네임 멘션·마크다운을 이스케이프하고
응답 멘션을 꺼서 랭킹에 이름이 올라가도 알림을 보내지 않습니다.

측정값은 앱에서 관측한 가방 증가이며 구매·거래가 포함될 수 있습니다.
랭킹은 각 계열의 수량 기준입니다. 시세나 가격 환산 점수는 사용하지 않습니다.
앱이 직접 실행하지 않은 수동 플레이의 완료 횟수는 추정하지 않습니다.
일별 날짜와 TOP 5는 인증 서버가 결정합니다.

읽기 키는 봇 서버에만 설정하고 사용자에게 노출하지 않습니다.
인증 서비스는 `supremiere/Dungeonhelper`의 `cloudflare/dungeonhelper-auth` 디렉터리에 있으며,
봇 DB와 분리된 Cloudflare D1에 집계를 저장합니다.
