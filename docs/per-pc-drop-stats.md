# PC별 내 기록과 랭킹

던전헬퍼 통계 API가 제공하는 `clients`별로 내 기록을 따로 표시한다.
같은 Discord 계정의 두 PC는 `닉네임1`, `닉네임2`로 각각 판수·수량·획득률을 계산한다.
내 기록은 한 번에 두 PC를 보여주고, 더 많으면 이전/다음 버튼으로 조회한다.
페이지는 요청한 본인만 조작할 수 있다. 기존 서버 응답도 그대로 지원한다.

랭킹은 서버에서 분리한 항목을 표시하며, 전체 드랍 통계는 기존 전체 합계를 유지한다.
PC가 기록되지 않은 과거 자료는 별도 `기존 기록`으로 남긴다. 추정 배분하지 않는다.

던전헬퍼 저장소의 `client-statistics.sql` 마이그레이션과 Worker 변경이 먼저 필요하다.
이 봇 변경만 적용해도 구버전 서버의 계정 합계가 자동 분리되지는 않는다.
PC 이름은 서버가 인증된 Discord 닉네임과 번호로 구성하며 사용자가 닉네임이나
타인의 계정을 입력하는 인증 절차는 추가하지 않는다.

검증: `python -m pytest tests/test_drop_stats.py -q`.
PC별 독립 분모, 전체 합계 유지, 기존 기록 분리, 멘션 이스케이프, 페이지의 본인 확인,
Discord 메시지 길이 제한과 기존 표시 회귀를 검사한다. 실제 Discord 게시 시험은 하지 않았다.
